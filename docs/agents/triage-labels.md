# Triage 标签

技能使用五个规范 triage 角色。本文件将角色映射到本仓库 GitHub Issues 使用的标签。

| 技能中的规范角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估此工单 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求已充分明确，可交由后台代理处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不会处理 |

技能提到某个角色时（例如“应用 AFK-ready triage 标签”），使用表中对应的 GitHub 标签。标签名称是协议标识，保留原文。
